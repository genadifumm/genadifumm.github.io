# Privacy policy

This app (rclone gdrive) is used only by its owner, on the owner's own computer.

It connects to the owner's own Google Drive only to upload, list and check the owner's own backup files. No data is collected, stored elsewhere, shared, sold or sent to anyone else. Data moves only between the owner's computer and the owner's Google Drive.

Access can be revoked at any time from Google Account settings: https://myaccount.google.com/permissions

## WhatsApp assistant ("Gena's assistant")

This is a private WhatsApp assistant used only by its owner. It replies only to the owner's own phone number and ignores messages from anyone else.

Messages the owner sends to it are processed by the assistant's server (Cloudflare Workers) and sent to the Anthropic Claude API to generate a reply. Voice messages are converted to text on Cloudflare Workers AI. Recent conversation history and reminders are stored only in the assistant's own database so it can answer in context. No data is sold, shared with third parties for marketing, or used for anything other than replying to the owner.

The owner can erase the conversation history at any time by sending "/reset" to the assistant. For any request about data, contact the owner of this site through GitHub: https://github.com/genadifumm
